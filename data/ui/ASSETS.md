## 国旗

38个现代国旗SVG来自 lipis/flag-icons，固定提交086f7e97d657358203916dbe84f61c2bccaa81eb，MIT许可。完整版权与许可保存在apps/web/public/flags/LICENSE.txt，逐文件来源、代码映射与SHA256见flag-sources.json。

源仓库及许可：https://github.com/lipis/flag-icons/blob/086f7e97d657358203916dbe84f61c2bccaa81eb/LICENSE 。本项目仅将4:3 SVG本地缓存，不修改国旗图形；构建运行不依赖第三方CDN。展示现代旗帜不宣称它是整个历史职业时期的旗帜。

DDR、RHO等历史国家单独列出，只显示本项目原创中性地球图形和原国籍代码，不替换为现代继承国家。未知代码同样保留原文；null显示地球和问号。加载失败不会删除代码。

## constructor 标识

本阶段真实官方/车队Logo覆盖**0个**。没有足够的独立授权记录，未批量下载任何F1官网或车队图片。

CONSTRUCTOR_MARKS为按稳定constructorId关联的许可登记表，未来每项必须提供来源URL、许可/授权URL、署名与审核日期，不能通过姓名或商业继承关联。当前所有constructor使用本项目原创、黑白中性方框首字母占位。占位符工具提示及无障碍文本明确注明“非官方队标”，不模仿品牌图形。

地球和占位符均为本项目编写的代码图形，无第三方图形复制。图像加载失败降级占位。所有名称来自既有只读constructor名称接口。单元测试的标志正常/失败分支采用原创本地测试图形，不能算作真实队标覆盖。

## P3.3 原创 constructor 徽章

真实队标仍为 0 个。constructorBadge 使用精确内部 ID 的确定性 FNV 派生色相、三种几何边框和两位识别码，配合名称首字母，取代阶段 C 的黑白方框。全部为项目原创 CSS/文字，不使用品牌图形；标注“非官方队标”。徽章不是业务身份，有限颜色与识别码可能碰撞，始终以唯一 ID 和完整名称区分 constructor，不合并历史继承关系。

## P3.4 极简时间线

游戏车队浮层与答案资料卡不再使用 constructor 徽章或 Logo。统一为本项目原创 CSS 细线、圆形序号和文字；constructor ID 仍是业务标识，序号只表示审核记录的 order。并列记录保留同序号及“同场先后未确认”。历史 ConstructorMark 组件和测试留作原素材代码记录，不用于本阶段时间线界面。没有新增第三方图形；国旗仍使用原 38 个本地 MIT SVG 及原许可文件。
