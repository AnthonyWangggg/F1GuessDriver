# 部署与运维入口

当前流程见 [维护指南](../docs/maintenance.md)。通用模板供人工审阅，不能直接覆盖正在使用的生产配置。

| 通用文件                 | 用途                           |
| ------------------------ | ------------------------------ |
| `nginx.conf`             | 反向代理参考                   |
| `f1-guess.service`       | 单实例 systemd 参考            |
| `production.env.example` | 无真实凭据的配置示例           |
| `roles.sql.example`      | 数据库角色参考，执行须另行批准 |
| `logrotate.conf`         | 日志轮换参考                   |

## 本地运维索引

以下目录保留原路径及哈希绑定，排除出公开源码。目录同时含阶段证据与有效工具，不能根据阶段名称判断是否废弃。

| 本地目录                               | 内容                                       |
| -------------------------------------- | ------------------------------------------ |
| `public-prep/`                         | 最终发布计划、证书准备、工具摘要与审批材料 |
| `private-access/`                      | 私有访问说明及连接工具                     |
| `p4d/`、`p4e/`                         | 私有部署、备份、回滚和配置证据             |
| `p4f/`                                 | 公网切换候选、Origin 与 CRL 维护           |
| `p4g/`、`p4h/`、`p4j/`、`p4k/`、`p4l/` | 验证、域名、证书和续期研究及冻结工具       |

使用前核对原部署交接记录、固定版本、TOOLS.sha256 与审批范围。候选脚本不能证明自动续期已经生效；历史 RESULT/PLAN 不能替代当前配置和新批准。

本次整理不移动以上目录，不修改证书、CRL、备份、告警和回滚工具。后续工具变化须交接路径与哈希，重新审阅生产绑定，不能只更新摘要消除不一致。
