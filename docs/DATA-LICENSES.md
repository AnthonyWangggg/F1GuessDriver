## 公开克隆后的重建

公开候选包含源码、Migration、锁文件、来源说明、许可及原创运行配置，但不包含完整历史数据库。`pnpm install --frozen-lockfile`、类型检查和构建不依赖被排除的历史事实文件。完整本地历史测试/审计需要上述私有证据，不能宣称裸公开克隆已包含完整重建输入。

1. 阅读所有来源条款，确认非商业用途或取得对应授权；需要商业用途时先联系数据权利人。
2. 从有权持有者取得与 data-publication.json 摘要一致的审核输入，保持本地；执行 `pnpm data:check-inputs`。不通过自动下载未经审核材料来规避授权。
3. 按 docs/P1-database.md 和审核文档取得固定版本源数据，迁移到独立数据库并导入。当前 API 可变，不能保证重新下载即可重现旧 valid 快照；精确恢复应使用管理员合法持有、加密保存的已验证备份，在独立恢复库先验证。
4. 执行历史测试、审计、快照与旧版摘要校验。缺失证据不得跳过断言、默认批准或填零；数据库备份及会话凭据始终留在私有存储。

生产 HTTP 包只需运行配置、Migration、摘要和许可证，不携带混合历史审计 JSON。维护导入/审核需锁定版本的源码工具及另外取得许可的本地源数据包。公开源码并不解决上线数据服务的非商业授权问题。
