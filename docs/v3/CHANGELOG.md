# Driver Guess 3.0 版本说明

Driver Guess 3.0 已在 [f1driverguess.online](https://f1driverguess.online/) 正式上线，生产生命周期为 `PUBLIC_VERIFIED`。

- 首页集中提供快速游戏、每日挑战和 BO3。
- BO3 提供服务端比赛状态、断线恢复和终局随机承诺复算。
- 增加账号、个人资料、积分与排行榜，积分按模式规则结算。
- 保留中文与英文车手检索、版本化猜测反馈和对局恢复。
- 采用独立 STG 与 PROD，先在 STG 验收，再晋升同一 Linux 制品。

当前生产应用提交与未来 GitHub `main` 的提交身份分别管理。发布记录以本地保存的应用提交、制品和控制器摘要为准。
